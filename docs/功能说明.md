# RE4 RhyLive Face：当前功能与封装方案

版本：0.2.0（Lua 面板、接收 DLL 导出版本与启动日志统一）。此说明以当前代码为依据；历史游戏内认可仅对应当时测试的角色和版本，本次构建与本机收包测试不代表重新完成实机验证。

## 当前 REFramework 界面能做什么

| 功能 | 当前能力 |
|---|---|
| 界面语言 | 默认中文，面板顶部一键切换中英文，语言选择自动保存。 |
| 手机输入 | 接收 RhyLive 无线发送的 OSC /Face，读取 52 个 ARKit 系数。无需 Warudo 转发。/Body 不参与驱动。 |
| 接收控制 | 设置监听 IPv4 和端口；启动、重新启动、停止接收。 |
| 连接状态 | 显示是否监听、实际端口、错误码、收包数、有效面部帧数、拒绝数和最后有效帧年龄。 |
| 面部驱动 | 驱动当前玩家角色的左眨眼、右眨眼、张嘴；默认映射涉及 15 个面部骨骼。 |
| 中性姿态 | 采集当前角色的骨骼基准；再开启或关闭面部驱动。此操作不是手机 ARKit 系数的零点校准。 |
| 响应与幅度 | 调整 Input response、52 个通道各自的 gain，以及位置增量倍率；支持全部 gain 重置为 1。位置增量倍率不改变旋转幅度。 |
| 通道显示 | 52 个 ARKit 通道分组显示，标明已映射通道数量；默认仅映射左右眨眼和张嘴。 |
| 手动测试 | 不依赖手机，为 52 个通道提供 0–1 测试滑条和全部归零；只有配置中有映射的通道产生骨骼动作。 |
| 参数保存 | 监听地址、端口、响应、断流超时、位置倍率与各通道 gain 在修改后延迟保存；脚本重置时尝试保存。接收、驱动、中性姿态和手动测试值不自动恢复。 |
| 模型校准 | 选取眨眼或张嘴通道；使用外部骨骼工具如 EMV 摆出终点姿态后采集，保存/重载映射 JSON。插件目前没有内置骨骼编辑器。 |
| 断流处理 | 可调断流超时；输入过期后释放驱动。手动测试模式按设计忽略手机。 |
| 角色变化 | 玩家或头部对象变更后关闭驱动并要求重新采集中性姿态。 |
| 故障诊断 | 导出接收诊断 JSON，查看输入轮询与面部回调次数。 |

## 已知边界

- 形态键工具分工：本仓库接收手机数据；[System](https://github.com/Funnyguysmz/RE4R-ShapeKey-System) 驱动形态键；[Studio](https://github.com/Funnyguysmz/RE4R-ShapeKey-Studio) 提供桌面界面和适配运行时；[导出器 Fork](https://github.com/Funnyguysmz/RE-Mesh-Editor-BlendShape) 制作模型通道。手机 RhyLive App 不属于本工具链的开源项目。
- 0.70.6 导出器的 RE4 两开关支持九个原生零位移接收口和 packed 位移加基础自定义法线，无 `normalRecalc`、无需 fins；保留已有法线方向，不自动生成卡通法线或逐表情独立法线。派生版已公开为 [v0.70.6-re4r.2 预发布](https://github.com/Funnyguysmz/RE-Mesh-Editor-BlendShape/releases/tag/v0.70.6-re4r.2)，两个 RE4 开关默认关闭；本版合并上游 0.70.6，RE4 packed/no-recalc 仍使用最终基础法线，不新增逐表情表面转动法线。详见[维护说明](https://github.com/Funnyguysmz/RE-Mesh-Editor-BlendShape/blob/v0.70.6-re4r.2/MAINTENANCE_NOTES.md)，无需改动 RhyLive 协议或运行时 API。导出器适用 GPLv3，基础运行时源码继续适用 MIT，第三方许可保留。
- 小玉独立 85 通道法线包已有用户认可；合并导出器与新 94 通道集成组合仍待实机确认。mouth9 路线须使用 System 配套 profile/原生映射或 Studio 配套运行时，不同时启用本面板骨骼 Drive face。
- [System v0.4.5-rc.1 预发布](https://github.com/Funnyguysmz/RE4R-ShapeKey-System/releases/tag/v0.4.5-rc.1) 提供接收口子集、`native_map_file`、逐口诊断、实时权重边界与通用 Leon/mouth9 映射，保留 91/9/NoTap，不改变 RhyLive 接收协议；模型 profile 和集成实机验证仍独立要求。

- 接收 52 个系数不代表当前有 52 种表情映射。默认实际驱动三项，其余系数可用于未来适配。
- 默认定位当前玩家；尚未实现 Ashley、NPC、多个角色的可选驱动目标。
- 当前是骨骼位置/旋转映射，没有实现通用 VRChat Shape Key / BlendShape 写入。
- Michele TEST8 已经由用户实测认可；其他模型是否合适取决于骨骼、权重和映射，不能声明所有换模通用。
- 主界面的参数保存至 `RhyLiveFace_settings.json`；语言选择单独保存，模型映射可保存至 `RhyLiveFace_profile.json`。中性姿态仅属于当前运行的角色对象。
- 没有自动启用接收/驱动、热键、预设管理、本机 IP 自动列出或输入手机零点校准。手机发送目标必须填写电脑实际 IPv4，不能填写监听地址 `0.0.0.0`。
- 游戏版本及 REFramework 更新后的兼容性需复核。当前二进制使用 REFramework API 1.15.0 / RE4。

## 这次已做的分包

主包包含 RhyLiveFace.dll、主 Lua、数学模块、默认映射、语言模块、安装说明、第三方许可和版本/哈希清单。不带测试发送器、编译库、调试符号、用户配置、个人字体工具或模型/游戏素材。

对外发布内容只包含面捕插件。

源码和历史测试证据保留在项目目录。当前 ZIP 来自本仓库重新构建的 DLL 与源码，按文件清单逐项核对 SHA256；未安装至游戏。项目自有代码适用 MIT LICENSE（Copyright (c) 2026 funnyguyz），第三方许可继续保留。

## 建议下一版界面

日常控制：连接状态 → 接收开关 → 采集中性姿态 → 面捕开关 → 响应速度 → 左右眨眼/张嘴幅度。

高级设置折叠：监听地址和端口、超时、位置增量倍率、映射选择与保存。

模型适配折叠：手动测试、终点采集、缺失骨骼提示。

诊断折叠：Packets、Face frames、Rejected、Age、回调次数、导出诊断。日常界面用“已连接 / 等待手机 / 输入中断 / 模型未校准”描述状态。

参数自动保存、分组通道和接收状态文字已在 0.2.0 实现。可继续考虑折叠调试项和映射预设。重新进入场景后仍须按对象重新采集中性姿态，不直接复用旧对象的运行基准。中文界面依赖宿主字体字形支持，个人字体工具不属于公开交付。

此节其余布局建议属于后续方案，不应作为当前已实现功能。0.2.0 保留既有骨骼姿态求解与驱动逻辑，扩展通道显示及参数保存。
